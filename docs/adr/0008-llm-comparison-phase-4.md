# ADR-0008: Runtime LLM karşılaştırması (Faz 4)

**Durum:** Planlandı (henüz karar verilmedi)
**Tarih:** 2026-07-24

## Bağlam

Runtime LLM olarak şu an `gpt-4.1-mini` kullanılıyor (bkz.
[ADR-0001](0001-llm-model-selection.md)), veri zenginleştirme
bağlamında verilmiş bir karardı. Runtime (RAG pipeline, intent
parsing, öneri üretimi) için `Qwen3 7B` ve `Turkish-LLM 7B`
(Ollama üzerinden, yerel) alternatifleri kalite/maliyet açısından
henüz kıyaslanmadı.

## Karar

Henüz verilmedi. `feature/rag-pipeline` kapsamında karşılaştırma
yapılacak.
